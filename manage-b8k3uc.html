設定 GitHub Token

這組 Token 是唯一的寫入鑰匙，只存在這台裝置的瀏覽器裡，不會傳給任何第三方。
申請方式：GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token。
Repository access 選 ict-E-catalog，Permissions 只需勾選 Contents: Read and write。

注意：本工具的防線是這組 Token —— 沒有它，任何人都無法修改任何型錄。 若需要連型錄清單都不給看，須把 repo 設為 Private（需 GitHub 付費方案）或改為只在本機開啟後台。
